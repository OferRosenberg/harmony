# OpenAI Harmony Command-Line Parser

A powerful command-line tool that reads binary token files (32-bit integers) and parses them back to OpenAI Harmony messages with detailed component analysis. This is the perfect companion to the Harmony Renderer.

## 🎯 **What It Does**

The Harmony Parser:

1. **Reads binary token files** (32-bit integers, little-endian)
2. **Parses tokens back to messages** using the Harmony format parser
3. **Displays message components** with roles, channels, and content
4. **Shows detailed analysis** of the conversation structure
5. **Provides multiple output formats** (detailed, compact, summary)

## 🔧 **Usage**

### **Basic Syntax**
```bash
python harmony_parser.py BINARY_FILE [OPTIONS]
```

### **Input Requirements**

#### **Binary File Format**
- **32-bit unsigned integers** (4 bytes per token)
- **Little-endian byte order**
- **No headers or metadata** (pure token sequence)
- **Generated by harmony renderer** or compatible tools

### **Output Modes**

#### **1. Detailed Output (Default)**
```bash
python harmony_parser.py tokens.bin
```

**Shows:**
- Complete message breakdown with all components
- Role, channel, recipient, content type for each message
- Full content text (truncated if very long)
- Parsing summary with statistics

#### **2. Compact Output**
```bash
python harmony_parser.py tokens.bin --compact
```

**Shows:**
- One-line summary per message
- Role, channel, recipient
- Content preview (first 100 characters)

#### **3. Summary Only**
```bash
python harmony_parser.py tokens.bin --summary-only
```

**Shows:**
- Total tokens and messages
- Message breakdown by role and channel
- No individual message content

### **Advanced Options**

#### **Verbose Output**
```bash
python harmony_parser.py tokens.bin --verbose
```

**Additional information:**
- File size and expected token count
- Encoding details
- Verification by re-rendering messages

#### **Token Preview**
```bash
python harmony_parser.py tokens.bin --show-tokens 10
```

**Shows first N tokens with decoded values:**
```
Token   1: 100257 → '<|start|>'
Token   2:   9125 → 'system'
Token   3: 100264 → '<|message|>'
...
```

#### **Help**
```bash
python harmony_parser.py --help
```

## 🛠️ **Integration Examples**

### **Batch Processing Script**
```bash
#!/bin/bash
# parse_all_tokens.sh

echo "Parsing all binary token files..."

for bin_file in *.bin; do
    if [ -f "$bin_file" ]; then
        echo "Processing: $bin_file"
        python3 harmony_parser.py "$bin_file" --compact > "${bin_file%.bin}_parsed.txt"
        echo "Saved to: ${bin_file%.bin}_parsed.txt"
    fi
done

echo "Batch parsing complete!"
```

### **Python Integration**
```python
#!/usr/bin/env python3
import subprocess
import sys
import json

def parse_binary_tokens(binary_file, output_format="detailed"):
    """Parse binary tokens and return results"""
    
    cmd = [sys.executable, "harmony_parser.py", binary_file]
    
    if output_format == "compact":
        cmd.append("--compact")
    elif output_format == "summary":
        cmd.append("--summary-only")
    
    result = subprocess.run(cmd, capture_output=True, text=True)
    
    if result.returncode == 0:
        return result.stdout
    else:
        raise Exception(f"Parsing failed: {result.stderr}")

# Example usage
try:
    output = parse_binary_tokens("tokens.bin", "compact")
    print("Parsing successful:")
    print(output)
except Exception as e:
    print(f"Error: {e}")
```

### **Analysis Script**
```python
#!/usr/bin/env python3
import struct
import openai_harmony
import os

def analyze_token_file(binary_file):
    """Analyze a binary token file"""
    
    # Read tokens
    tokens = []
    with open(binary_file, 'rb') as f:
        while True:
            data = f.read(4)
            if not data:
                break
            token = struct.unpack('<I', data)[0]
            tokens.append(token)
    
    # Initialize encoding
    os.environ['TIKTOKEN_ENCODINGS_BASE'] = 'vocab_files'
    encoding = openai_harmony.load_harmony_encoding("HarmonyGptOss")
    
    # Parse messages
    messages = encoding.parse_messages_from_completion_tokens(tokens, None)
    
    # Analyze
    print(f"File: {binary_file}")
    print(f"Tokens: {len(tokens)}")
    print(f"Messages: {len(messages)}")
    print(f"File size: {len(tokens) * 4} bytes")
    
    # Role breakdown
    roles = {}
    for msg in messages:
        role = msg.author.role.value
        roles[role] = roles.get(role, 0) + 1
    
    print("Roles:", roles)
    return tokens, messages

# Usage
tokens, messages = analyze_token_file("example.bin")
```

## 🔍 **Binary File Analysis**

### **File Format Verification**
```bash
# Check file size (should be divisible by 4)
ls -la tokens.bin

# Expected: file_size = token_count × 4 bytes
# Example: 624 bytes = 156 tokens × 4 bytes
```

### **Manual Token Reading (Python)**
```python
import struct

def read_first_tokens(filename, count=10):
    """Read first N tokens from binary file"""
    with open(filename, 'rb') as f:
        for i in range(count):
            data = f.read(4)
            if not data:
                break
            token = struct.unpack('<I', data)[0]
            print(f"Token {i+1}: {token}")

# Usage
read_first_tokens("tokens.bin", 5)
```

### **File Validation**
```bash
# Check if file size is valid (divisible by 4)
python3 -c "
import os
size = os.path.getsize('tokens.bin')
tokens = size // 4
remainder = size % 4
print(f'File size: {size} bytes')
print(f'Expected tokens: {tokens}')
print(f'Valid format: {remainder == 0}')
"
```

